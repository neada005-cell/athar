# أثر

جدار أثر الحي لنادي أثر — ملتقى الأندية.

## فتح الموقع من الجوال

مستودع GitHub يحفظ **الكود**. عشان يصير رابط يفتح بدون قروك:

1. ادخلوا [vercel.com](https://vercel.com) من الجوال
2. سجّلوا دخول بـ GitHub
3. Import Project → اختاروا `athar`
4. Deploy

بعدها يعطيكم رابط مثل `athar.vercel.app`. هذا يبقى حتى لو خلص اشتراك قروك.
